# 🎵 MP3 后缀修复工具

纯前端网页工具，帮助用户批量修复 MP3 文件扩展名。整个过程在浏览器本地完成，**不上传任何文件**，保证数据安全。

## 项目背景

从网页下载音乐文件时，部分网站不会正确保存扩展名，导致文件显示为：

```
夜曲
稻香.download
晴天.temp
```

虽然这些文件实际上都是 MP3 文件，但由于缺少 `.mp3` 后缀，Windows 无法直接识别，也无法用播放器打开。本工具通过读取文件头部魔法数字（Magic Number）判断真实格式，并自动修复扩展名。

## 功能特性

- 📁 **选择本地文件夹** — 基于 File System Access API
- 🔍 **文件头识别** — 检测 ID3 标签和 MPEG 帧同步头，不依赖扩展名
- 📊 **文件分类** — 三态展示：已正确、可修复、跳过
- 🛠️ **批量修复** — 创建输出目录，复制文件并添加 `.mp3` 后缀
- 📈 **进度显示** — 扫描和修复过程实时反馈
- 🔒 **纯本地处理** — 不上传任何数据，无需服务器

## MP3 格式识别原理

不依赖文件扩展名，通过读取文件头部字节进行判断：

| 特征          | 偏移     | 字节                               |
| ------------- | -------- | ---------------------------------- |
| ID3v2 标签    | 文件开头 | `49 44 33`（"ID3"）                |
| MPEG 帧同步头 | 帧开头   | `FF FB`、`FF FA`、`FF F3`、`FF F2` |

同时满足任一条件即判定为 MP3 文件。
